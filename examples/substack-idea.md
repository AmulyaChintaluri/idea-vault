# Sample Substack idea

This example illustrates how the workflow could classify a message.

**Telegram message**

> Substack idea: Why I keep planning projects instead of starting them.

**Example Google Sheets entry**

| Field | Value |
| --- | --- |
| Title | Why I keep planning projects instead of starting them |
| Summary | An essay about how planning can become a way to delay starting. |
| Category and worksheet | Writing |
| Type | Essay |
| Destination | Self Publish |

The script records the idea in **All Tasks** and adds it to the **Writing** tab with **Self Publish** in the destination field.
